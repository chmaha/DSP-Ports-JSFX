Finger on the Pulse - sample data licence
==========================================

FingerOnThePulse.flac (Dependencies/FingerOnThePulse) holds the 45 stereo samples of "Fender Finger" from The No Budget Band bass collection by
Jeff Glatt (https://www.bandshed.net/sounds/sfz/, nbb_basses.zip), 16-bit 44.1 kHz, joined into one FLAC file
without other changes. The loop points stored in the original sample files are kept in FingerOnThePulse.txt, which also
holds the region data compiled from fender_finger_full.sfz. Both are played by a JSFX port of the sfizz SFZ engine.

The set's licence file reads:

No affiliation with the makers of the instruments the sets are named after.

The JSFX code (FingerOnThePulse.jsfx) is released separately under the GPLv3+ licence.
