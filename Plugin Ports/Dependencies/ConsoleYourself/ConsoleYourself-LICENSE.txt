Console Yourself Super NES samples (Dependencies/ConsoleYourself)
================================================================

ConsoleYourself.flac holds the 203 BRR samples of Doug Fraker's SNES sample collection
(https://github.com/nesdoug/SNES_13, MUSIC/More_Samples, commit 02bc588), unchanged, joined in order
with the two-byte loop header of each .brr file removed. The bytes are stored as 16-bit FLAC sample values
and are not audio. ConsoleYourself.txt holds the sample table: categories, sizes, loop points, tuning,
the envelopes from each .gsi instrument file, names and waveform previews.

Note from the collection (MUSIC/More_Samples/NOTES.txt):

I (Doug Fraker) made all these samples
Consider them public domain
(free to use)

for SNESGSS
.gsi is the instrument file 
(instruments tab/load)
SNESGSS can export the original WAV from it.
(intruments menu/extract source wav)

All samples are tuned to B +21 cents, usually
having a loop of 32,64,128,or 256 samples per loop

except the drums have not been retuned
nor has the "WhistleG" sample

.brr
brr versions have been included, which can be
used for SMW, AddmusicK.
These brr files have a 2 byte loop point at
the beginning of the file. You may need to
remove those 2 bytes for purposes other than SMW.
