Bright Spark - sample data licence
===================================

BrightSpark.flac (Dependencies/BrightSpark) holds the 46 stereo samples of "Bright Rick" from The No Budget Band bass collection by
Jeff Glatt (https://www.bandshed.net/sounds/sfz/, nbb_basses.zip), 16-bit 44.1 kHz, joined into one FLAC file
without other changes. The loop points stored in the original sample files are kept in BrightSpark.txt, which also
holds the region data compiled from bright_rick_full.sfz. Both are played by a JSFX port of the sfizz SFZ engine.

The set's licence file reads:
  Created by Jeff Glatt
  License: http://creativecommons.org/licenses/by-sa/4.0

No affiliation with the makers of the instruments the sets are named after.

The JSFX code (BrightSpark.jsfx) is released separately under the GPLv3+ licence.
